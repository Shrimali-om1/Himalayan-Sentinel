# 5–10 minute demonstration guide

1. **Situation Room (1 minute):** introduce Kullu–Manali illustrative pilot scope and the non-warning disclaimer. Show source status and rainfall provenance.
2. **Map and screening (2 minutes):** turn map layers on and select a hazard-screening point. Explain the map fallback and attribution.
3. **Hazard Analysis (1 minute):** show component values and the 45/55 heuristic. State that the score is not probability.
4. **Disaster Chain (1 minute):** select each node and distinguish inferred, hypothesis, and simulated relationships.
5. **Impact Analysis (1 minute):** change the buffer and explain that proximity is not expected damage.
6. **Scenario Studio (1 minute):** apply +25% rainfall. Confirm that results are labelled simulated and terrain inputs stay unchanged.
7. **Incident report and summary (1 minute):** submit a sample report and show unverified status; generate a report that retains limitations.
8. **Close (1 minute):** open Data Sources and Limitations. Explain which pipeline items need real DEM/OSM/PostGIS data next.
