# User guide

1. Open **Situation Room** and read the persistent demo/provenance indicator before interpreting the map or metrics.
2. Toggle map overlays and select an illustrative point to open its context. The map can fall back gracefully if the basemap is unavailable.
3. In **Hazard Analysis**, inspect rainfall/terrain components and the explicit weighting. Do not read its classes as likelihoods.
4. In **Disaster Chain**, click nodes to inspect evidence type. Arrows communicate hypotheses or simulated links only.
5. In **Impact Analysis**, change the buffer and recalculate infrastructure proximity. It is a screening result, not impact prediction.
6. In **Scenario Studio**, state the adjustment, run it, and compare simulated values.
7. In **Incident Reports**, file a careful report and see that it stays `UNVERIFIED USER REPORT`. Generate the deterministic summary when needed.
8. Open **Data Sources** before presenting any result to establish classification and limitations.
